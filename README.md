# Impossible Quiz Remake

This is a short remake of the game The Impossible Quiz in Godot. 

# Features:

- 16 Questions in total
- Skips that can be earned ingame
- Lives system
- Unique mechanics in some questions that will need you to think outside of the box.

# How do I play this?
[Itch.io](https://nottacos3.itch.io/impossible-quiz-remake)

# How do I build this?
Put it into godot engine and there you go!
